# 《图解算法》难度分层索引

> 同知识点搭配 **简单 / 中等 / 困难** 三道题，适配五阶闭环中"从基础刷题到难题刷题"的进阶路径。
> 建议顺序：简单（理解模板）→ 中等（变体应用）→ 困难（综合融合）。

---

## 难度定义

| 难度 | 含义 | 对应阶段 |
|:---:|:---|:---|
| 🟢 简单 | 模板直接套用，无变体 | 第三阶·背诵模板 |
| 🟡 中等 | 模板变体，需1-2处改动 | 第四阶·真题刷题 |
| 🔴 困难 | 多技巧融合或边界复杂 | 第五阶·复盘沉淀 |
